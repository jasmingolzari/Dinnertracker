
# AI tools

AI tools have been used as a support during the development of
Dinnertracker. The main tool used has been ChatGPT and Claude. It has primarily
been used for guidance and troubleshooting when the group has encountered
problems during development with no other option left.

For example, ChatGPT has been used to help us understand unfamiliar
concepts in Java, Git, Maven, JavaFX, and the project structure. It has
also been used to explain error messages and suggest possible ways of
investigating technical problems. In situations where we were unsure
about how different parts of the project worked together, we used the
tool to discuss possible solutions and clarify the underlying concepts.

The AI tool has also been useful when working with Git and GitLab. For
example, it has helped us understand branches, commits, merging, pull
requests, and how to recover from problems with the local working tree.
Rather than simply applying suggested commands, we have used the
explanations to understand what the commands do and why they are
appropriate.

The AI tool has not been used to generate functionality for the
project. The group members are responsible for implementing, testing,
and adapting the code in the project. Suggestions from the AI have been
treated as guidance, and we have evaluated whether they fit our project
before using them.

Overall, we use AI as a learning and development aid, particularly when
we get stuck or need another explanation of a technical problem. The
purpose is to help us understand and solve problems ourselves rather
than to replace our own development work.
