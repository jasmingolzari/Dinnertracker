# AI Tools

AI tools have been used as support throughout the development of Dinnertracker. The main tools used have been ChatGPT and Claude. They have primarily been used for guidance, learning, troubleshooting, and assistance with technical documentation.

## Learning and technical guidance

AI tools have helped group members understand unfamiliar concepts and technologies, including Java, Git, Maven, JavaFX, REST APIs, and the project's modular structure. They have also been used to explain error messages, investigate technical problems, bugs, and discuss possible solutions when the group has encountered difficulties during development.

The tools have supported the group's understanding of how the different modules and technologies work together. Their explanations have been used as a learning aid to help group members understand both how to approach problems and why particular solutions may be appropriate.

## Git and collaboration

AI tools have been used to clarify Git workflows and concepts such as branches, commits, merging, pull requests, and resolving problems with the local working tree. They have helped us understand the purpose of different Git commands and how to use them safely when collaborating on the project, and working locally. 


## Implementation, testing, and documentation

Throughout the releases, AI tools have also been used as support when working with the project's architecture, Maven configuration, testing, code coverage, and documentation.

During development, the tools have helped explain technical requirements, investigate errors, discuss implementation approaches, and improve written documentation. Suggestions have been considered in the context of the existing project rather than treated as automatically correct. 

The group members remain responsible for reviewing suggestions, making implementation decisions, adapting solutions to the project, and ensuring that the resulting code and documentation are appropriate. 


## Responsible use

AI tools have been used as supplementary support rather than as a replacement for the group's own understanding and decision-making. Group members have been responsible for evaluating the relevance and correctness of suggestions before incorporating them into their work. 

The purpose of using AI tools has been to support learning, problem-solving, and development while helping us build our own technical understanding.
